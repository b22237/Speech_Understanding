====================================================================
AUDIO DATA MANIFEST 
====================================================================
This project programmatically streams its audio data using the 
Hugging Face `datasets` library to ensure clean, standardized 
speech samples without requiring local storage of large datasets.

Dataset Source: LibriSpeech ASR (Automatic Speech Recognition)
Repository:     "librispeech_asr" (via Hugging Face)
Config/Split:   "clean" / "validation"
Access Method:  Streaming Mode (First iterated sample)
