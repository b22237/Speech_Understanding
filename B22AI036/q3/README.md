# Q3: Ethical Auditing & "Documentation Debt" Mitigation

This sub-folder contains the complete implementation for the "Sound Check" audit, privacy-preserving biometric transformation, and fairness-aware training loop for speech recognition.

## 📁 Project Structure

- **audit.py**: Programmatically audits the Mozilla Spontaneous Speech dataset for representation bias and "Documentation Debt."
- **privacymodule.py**: A PyTorch `nn.Module` that performs biometric obfuscation (pitch and formant shifting) to protect speaker privacy.
- **pp_demo.py**: A demonstration script that applies the privacy module to samples in the `examples/` directory.
- **train_fair.py**: A simulation of an ASR training loop utilizing a custom "Fairness Loss" term to minimize demographic performance gaps.
- **evaluation_scripts/**:
    - **evaluate_fad.py**: Script to calculate the Fréchet Audio Distance (FAD) to detect "Toxicity Traps" or audio artifacts.
- **examples/**:
    - **original/**: Place raw dataset samples here for processing.
    - **obfuscated/**: Output directory for biometric-transformed audio.
- **audit_plots.pdf**: Visualizations generated by the audit script.
- **q3_report.pdf**: A 4-page summary of results, mathematical formulations, and ethical considerations.

## Getting Started

### 1. Installation
Ensure you are using Python 3.8+ and install the required dependencies:
```bash
pip install -r requirements.txt
```

### 2. Running the Audit
Place the `ss-corpus-en.tsv` file in the root of the `q3/` folder and run:
```bash
python audit.py
```

### 3. Biometric Transformation Demo
To test the privacy module, place 5-10 `.mp3` or `.wav` files in `examples/original/` and execute:
```bash
python pp_demo.py
```

### 4. Fairness Training Simulation
To observe the custom loss function minimizing the performance gap between demographics:
```bash
python train_fair.py
```

### 5. Validation (FAD)
To check the acceptability of the transformed audio:
```bash
cd evaluation_scripts
python evaluate_fad.py
```

## ⚖️ Ethical Findings Summary
Our audit identified a **47.40% Documentation Debt** for gender and an **85.19% Debt** for accents. The primary representation bias is a skew toward **female speakers in their twenties** from the **United States**. The implemented fairness loss successfully reduced the demographic performance gap to a penalty of **0.0226**, while the FAD score of **6.6730** highlighted the inherent trade-off between speaker privacy and audio acceptability.
